# lhg-sp-product：产品页七要素

> 目标：把"有个产品页"变成"能卖货的产品页"。
> 核心纪律：**七要素缺一项，页面就不许上线**——产品页是离钱最近的一页，每处缺项都是漏斗上的洞。

## 1. 何时使用

- `/lhg-shopify:product-page` → 全程按本 skill 执行
- 新建产品页 → 按第 2 节逐项落实
- 老产品页转化率低 → 按第 6 节诊断清单找洞
- 产品文案不知道怎么写 → 第 4 节文案三问

## 2. 输入与输出

- **输入**：产品资料（名称、价格、卖点、图片、目标人群）
- **输出**：七要素全部落实的产品页 + 缺项清单（改前）/落实清单（改后）
- **不输出**：整站装修、结账流程——那是 lhg-sp-plan / lhg-sp-checkout 的事

## 3. 产品页七要素

按**用户视线顺序**排列，也是落实优先级：

### 要素 1：价格锚点（首屏必须一眼看到）

- 价格带货币符号（¥299，不是 299），原价划线价并排（¥399 → ¥299）
- 价格旁边 1 句"凭什么值"：例"双层真空，保温 12 小时"
- **坑**：价格藏在页面底部——用户翻不到就等于没有价格

### 要素 2：多图（≥3 张，有分工）

1. 主图：产品正面，干净背景
2. 细节图：材质/做工特写（解决"质量靠谱吗"）
3. 场景图：产品在真实使用场景里（解决"适合我吗"）
4. 尺寸图：与参照物对比（解决"多大"——退货头号原因就是"和想象不一样大"）

每张图写 alt（加载失败时的体面，也是搜索入口）。

### 要素 3：加购按钮（首屏 + 文案结尾各一处）

- 首屏一处（价格下方），长文案结尾再一处（看完卖点直接买）
- 按钮文案用动作词："加入购物车""立即购买"，不许用"提交""确定"
- 移动端：按钮宽度 ≥ 屏幕 80%，拇指够得着

### 要素 4：信任徽章（加购按钮旁边）

包邮 / 7 天退换 / 正品保障 / 安全支付，至少出现 2 个。
这是临门一脚：用户手指悬在按钮上时，徽章负责推一把。

### 要素 5：评价区（零评价也要留位置）

- 有评价：放 3–5 条带图评价，好评差评比例真实（全是五星反而假）
- 零评价：留出评价区 + 写"已有 X 人加购"，上线后持续填充
- **坑**：编造评价——被发现一次，店铺信任永久归零

### 要素 6：FAQ（挡掉一半客服咨询）

必备 4 问模板，照着改：

1. 发货时效？（"48 小时内发货"）
2. 运费多少？（"全国包邮"或写清标准）
3. 尺码/规格怎么选？（给对照表，不许让用户猜）
4. 坏了/不合适怎么办？（指向退换货政策页）

### 要素 7：物流说明（运费刺客预警）

- 写清：运费金额、发货时效、送达时效、快递公司
- 不知道的写"咨询客服"，不许编"3 天必达"
- 跨境：写清是否含税、清关要多久——这是跨境退货头号雷区

## 4. 文案三问

每处文案写完，自问三遍：

1. **3 秒能看懂吗**：用户扫一眼，知道这句在说什么吗？术语、缩写、长难句 → 重写
2. **不买的理由被挡住了吗**：贵？→ 价格锚点；怕假？→ 信任徽章；怕不合适？→ 尺寸图+FAQ
3. **有没有吹牛**：见第 5 节违禁词表，吹牛的词删掉，换成可验证的说法

## 4.5 首屏文案模板（照着填）

```
【产品名 + 核心规格】          ← 例：神奇保温杯 500ml
【一句话卖点】                  ← 例：双层真空，保温 12 小时
【价格锚点】¥299  <s>¥399</s>   ← 原价划线，折扣一目了然
【信任徽章】✓包邮 ✓7天退换
【按钮】加入购物车 / 立即购买
```

填完自查：删掉产品名，还能猜出卖的是什么吗？能 → 卖点写明白了；不能 → 回炉。

## 5. 文案违禁词（启发式，非穷尽）

以下词出现在产品页文案里，审计脚本标 warning，人工必须处理：

- 极限词：全网最低、第一、顶级、绝无仅有、史无前例
- 绝对承诺：保证治愈、永不磨损、100% 有效（除非真有检测报告且敢公示）
- 医疗/金融功效词：出现在普通商品上直接下架风险

替换原则：吹牛 → 可验证。"最好的保温杯" → "双层真空，实测保温 12 小时"。

## 6. 老页面诊断清单

转化率低的产品页，按这个顺序找洞：

1. 首屏 3 秒：价格看得到吗？加购按钮找得到吗？
2. 图片：够 3 张吗？有尺寸图吗？
3. 信任：徽章有吗？评价有吗？
4. 文案：FAQ 挡住了退货理由吗？物流写清了吗？
5. 移动端：按钮点得到吗？字看得清吗？

一次只补最浅的那个洞，补完看数据再补下一个。

## 7. 反模式

1. **图片堆砌**：10 张图全是摆拍，没有一张讲尺寸/细节——多不等于好
2. **文案自嗨**："匠心之作，致敬生活"——用户不知道你在卖什么
3. **价格躲猫猫**："咨询客服获取报价"——99% 的用户直接关掉
4. **评价造假**：编 100 条五星好评——被发现即社死
5. **运费刺客**：产品页写包邮，结账页加收 50 运费——弃单率飙升且差评预定

## 8. 自检与反馈

### 质检门（产品页交付前自查）

- [ ] 七要素逐项打勾，无缺项
- [ ] `shopify_audit.py` 的 PROD-* 规则全绿
- [ ] 文案三问都通过，无违禁词
- [ ] 手机上看一遍：按钮点得到、字看得清

### 标准冒烟用例

1. 给一个只有标题和 1 张图的产品 → 输出缺项清单 = 6 项（价格/加购/徽章/评价/FAQ/物流）
2. 文案含"全网最低" → 标出并给出替换说法

### 反馈

发现 bug 或有改进建议，以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-shopify/issues，正文写清"复现步骤 → 实际表现 → 期望表现"。
