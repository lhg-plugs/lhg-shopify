# lhg-sp-trust：信任元素与移动端

> 目标：让第一次来的用户敢下单，让手机来的用户买得顺。
> 核心纪律：**信任四件套缺一件不许发布；移动端没看过不许发布**——这两条是独立站的生死线。

## 1. 何时使用

- 发布前 → 全流程（第 2–6 节）
- 用户问"为什么没人买" → 先查第 2 节四件套，再查第 6 节评审清单
- 只做移动端适配检查 → 跑第 4 节
- 脚本审计之后 → 按第 6 节人工评审清单过一遍机器抓不到的

## 2. 输入与输出

- **输入**：站点目录（含 site_spec.json）
- **输出**：信任元素落实清单 + 移动端问题清单 + 人工评审结论（过/不过）
- **不输出**：页面重做方案——发现大问题打回 lhg-sp-plan

## 3. 信任四件套

### 件 1：退换货政策（独立成页）

必须写清四件事，缺一不可：

1. **天数**：7 天无理由 / 30 天质量问题，写具体数字
2. **条件**：什么状态能退（未拆封/不影响二次销售写清楚）
3. **流程**：找谁（客服邮箱/电话）→ 怎么寄 → 几天退款
4. **谁出运费**：质量问题卖家出，无理由买家出——写清楚，不许含糊

只写"支持退换"不写天数的，等于没写。

### 件 2：联系方式（页脚常驻）

- 至少两样：邮箱 + 电话/地址/在线客服三选一
- 邮箱用企业域名（support@你的店.com），不用 gmail/qq 邮箱——免费邮箱=皮包店既视感
- 电话写清服务时间（"工作日 9:00–18:00"），没人接的电话不如不写

### 件 3：支付标识（结账页可见）

- Visa / Mastercard / PayPal / 本地支付，实际支持哪种就展示哪种
- 标识旁边配一句"安全支付 · SSL 加密"
- **坑**：展示了 PayPal 标识但实际不支持——用户点进去发现没有，信任直接清零

### 件 4：隐私政策（独立成页）

- 写清收集什么信息（订单履约必需）、用来干什么、不卖给第三方
- 一句话版本放在结账页："我们仅收集订单履约所必需的信息"

### 加分件（不是 blocker，但做了加分）

- 关于我们：讲清楚"我们是谁"，新店尤其需要
- 服务条款：纠纷时的护身符
- 真实地址：有实体地址的店，信任度上一个台阶

## 4. 移动端适配检查

独立站流量大多来自手机：**先看手机，再看桌面**。

| 检查项 | 标准 | 常见翻车 |
|---|---|---|
| viewport | 每个页面都有 viewport meta | 整站缩成一团 |
| 字号 | 正文 ≥14px，按钮文字 ≥16px | 10px 小字看不清 |
| 按钮 | 高度 ≥44px，宽度 ≥屏幕 80% | 拇指点不到 |
| 横向滚动 | 无横向滚动条 | 固定 1200px 宽度撑爆 |
| 图片 | 自适应宽度，不撑破布局 | 大图溢出 |
| 表单 | 输入框调起对应键盘（电话调数字键盘） | 全是文本键盘 |

| 表单 | 输入框调起对应键盘（电话调数字键盘） | 全是文本键盘 |
| 错误页 | 404/500 页面有回首页入口 | 死路一条 |
| 加载 | 首屏 3 秒内出内容 | 白屏 5 秒 |

### 移动端速查口诀

"一指禅测试"：只用一根拇指，从首页逛到支付页，全程不用双指缩放、不用横向拖动——过了这关，移动端基本合格。

## 5. 首屏 3 秒测试

打开首页，心里默数 3 秒，回答三个问题：

1. 这家卖什么？
2. 卖给谁 / 解决什么问题？
3. 为什么在他家买（而不是别家）？

答不上来任何一个 → 首屏重做。这是人工评审里最重要的一项，机器替代不了。

### 首屏三件套（过了 3 秒测试的标配）

1. **一句话价值主张**：大标题 ≤15 字，说清卖什么+好在哪
2. **一个行动按钮**："选购""查看爆款"，首屏必须有一个
3. **一张信任背书**：销量数字 / 评价摘录 / 媒体报道三选一

三件套缺一件，首屏就少一分说服力；三件全有，3 秒测试基本能过。
记住：首屏不是"好看"就行，是"3 秒内让人知道买什么、为什么买"。

## 6. 人工评审清单（脚本之后必过）

脚本（shopify_audit.py）抓得到"有没有"，抓不到"好不好"。下面这些必须人眼过：

- [ ] 首屏 3 秒测试通过（第 5 节）
- [ ] 结账全流程走一遍（按 lhg-sp-checkout 第 5 节检查表）
- [ ] 退换货政策读一遍：天数/条件/流程/运费四件事都在吗？
- [ ] 手机实测：从首页逛到支付页，全程无横向滚动、无点不到的按钮
- [ ] 文案无吹牛词（见 lhg-sp-product 第 5 节）
- [ ] 所有对外链接（支付、物流查询）点得开，不是 404

## 7. 反模式

1. **信任页后补**："先上线，以后再加政策页"——以后就是没有
2. **免费邮箱客服**：support@gmail.com —— 省小钱，丢大信任
3. **标识造假**：展示不支持的支付品牌——被发现一次永久拉黑
4. **桌面端思维**：在 27 寸显示器上调好就发布——用户在手机上看到的是另一坨
5. **政策复制粘贴**：从别家店复制退换货政策，留着别人的店名和电话——真实翻车案例
