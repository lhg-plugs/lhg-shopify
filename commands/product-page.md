# /lhg-shopify:product-page —— 产品页打磨

用户输入在 `$ARGUMENTS` 中：`[产品页路径或产品名]`。加载 `lhg-sp-product` 全程指导，改完必须跑 `/lhg-shopify:shopify-audit`。

## 流程

1. **盘点现状**：打开产品页（或产品资料），对照 lhg-sp-product 第 2 节"产品页七要素"打勾打叉，输出缺项清单给用户看。
2. **逐项补齐**：缺哪项补哪项，顺序建议：价格锚点 → 多图 → 加购按钮 → 信任徽章 → 评价 → FAQ → 物流说明。补一项勾一项。
3. **话术三问**：每处文案写完自问三遍——"用户 3 秒能看懂吗""不买的理由被挡住了吗""有没有吹牛的词"（吹牛词见 lhg-sp-product 第 5 节反模式）。
4. **跑审计**：`shopify-audit` 里 PROD-* 规则全绿才算完；blocker 没清零不许说"做好了"。

## 硬规则
- 产品页没有价格就上线 → 不许。
- 用"全网最低"" guaranteed 最好"类极限词 → 不许（见反模式）。
