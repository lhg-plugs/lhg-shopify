# /lhg-shopify:shopify —— 一句话开店流水线

用户输入在 `$ARGUMENTS` 中：`[店铺定位/主营品类] [--lang zh|en]`。语言缺省中文。

全程加载插件 skills：`lhg-sp-plan`（建站规划）、`lhg-sp-product`（产品页）、`lhg-sp-checkout`（结账流程）、`lhg-sp-trust`（信任元素与移动端）。搭建工作可分派给 `site-builder` agent，完成后必须跑 `shopify-audit`。

## 流程

### 1. 规划（加载 lhg-sp-plan）
- 问清三件事：卖什么（1 个主类目）、卖给谁（目标人群）、语言与币种。不知道就按"单品站、中文+美元、30 天冷启动"默认走，不许反复追问。
- 输出 `site_spec.json`（站点施工图）：页面清单、导航、信任元素清单、结账步骤定义。**spec 没定，不许画页面。**

### 2. 选品页与产品页（加载 lhg-sp-product）
- 首页：首屏价值主张一句话、选品页（类目页）三件套（筛选/排序/爆款位）。
- 产品页按第 2 节"产品页七要素"逐项落实：多图、价格锚点、评价、FAQ、加购按钮、信任徽章、物流说明。

### 3. 结账流程（加载 lhg-sp-checkout）
- 按第 3 节四步结账：信息填写 → 配送 → 支付 → 确认；每一步有"回退"按钮，不许死路。
- 必备：游客结账、订单摘要常驻、运费计算器、支付方式 ≥2 种。

### 4. 信任元素（加载 lhg-sp-trust）
- 四大件：退换货政策页、联系方式（邮箱/电话/地址至少其二）、支付标识、隐私政策页。缺一件都不许发布。

### 5. 发布自检
- 跑 `/lhg-shopify:shopify-audit`，blocker 清零才交付。
- 发布命令（deploy/publish）前 hook 会自动校验 `site_spec.json` 完整性与信任元素，被拦截就修站，不要关 hook。
- 交付物：站点文件目录 + `site_spec.json` + 审计报告（三件套，缺一不可）。

## 硬规则
- 信任元素四件缺一件就发布 → 不许（这是本插件与"裸奔站"的分界线）。
- 结账页没有游客结账 → 不许。
- 为通过自检改审计脚本规则 → 作弊，不许。
